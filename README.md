# Anemoi Matrix — Navigation Beyond Deception

Scroll-driven maritime RF authentication story. A ship sails across a virtual sky and ocean while the voyage reveals spoofing, interception, authentication, and restored trust.

## Run

```bash
npm install
npm run dev
```

## Voyage arc

1. Voyage opens on sky + waves  
2. Open RF channel (no verification)  
3. Spoofing attack enters the signal  
4. Deception looks “normal” on the bridge  
5. Ambastion intercepts → Capture / Authenticate / Filter / Deliver  
6. Protected voyage on clean authenticated RF  
7. Beyond deception + demo CTA
